# ASE Tesi MultiRobot Process

A Java-based project for multi-robot process coordination and management as part of an ASE (Advanced Software Engineering) thesis.

## Overview

This project implements a comprehensive system for managing and coordinating multiple robotic processes. It provides tools and frameworks for distributed robot control, task scheduling, and inter-robot communication.

## Features

- Multi-robot coordination framework
- Process management and scheduling
- Robot task distribution and execution
- Communication protocols for distributed systems

## Technology Stack

- **Language**: Java
- **Build Tool**: Maven/Gradle (configure as needed)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 11 or higher
- Maven or Gradle (depending on your build configuration)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/omardinari02/ASE_Tesi_MultiRobot_Process.git
cd ASE_Tesi_MultiRobot_Process
```

2. Build the project:
```bash
mvn clean install
# or
gradle build
```

3. Run the application:
```bash
mvn exec:java
# or
gradle run
```
